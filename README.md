# SemEval 2025 Task 13: Machine-Generated Code Detection

This project was done as a part of the **SemEval 2025 Task 13** competition hosted on Kaggle. In this task, given a snippet of source code, have to determine whether it was written by a **human** (label 0) or generated by an **AI/LLM** (label 1). We trained and evaluated six model architectures ranging from classical ML baselines to deep learning sequence models, across the full 500,000-sample training set.

## Dataset

| Property | Details |
|---|---|
| Competition | SemEval 2025 Task 13 (Kaggle) |
| Training set | 500,000 samples |
| Validation set | 100,000 samples |
| Class balance | ~47.7% Human / ~52.3% Machine |

Data files are not included in this repository. Download from Kaggle: https://www.kaggle.com/datasets/daniilor/semeval-2026-task13?resource=download

Place the `.parquet` files inside the `data/` directory before running any scripts.

| TextCNN (G) | 96.13% | 0.9613 | 64.0 min (GPU) |
